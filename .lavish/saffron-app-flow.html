3

The hero loop: one edit pipeline, three ways in

What happens between a click and the recipe changing? Clicks, chat and voice all feed the same Gemini edit pipeline, so a fix to that pipeline helps all three at once.

4

What happens during a search

Why does search feel fast when the agent takes a minute? Cached matches load from Tiger in under a second, and the agent's slow work is shown live instead of hidden behind a spinner.

5

Cook mode and voice

When is the mic listening, and what can voice do? The mic is on only in cook mode, and voice uses the same tools and edit pipeline as clicks.

next_step · previous_step · go_to_step · repeat_step
Moves the focused step and reads it aloud.
start_timer · list_timers · cancel_timer · mark_step_done
Same timer tray and step states as tapping.
edit_recipe(instruction)
Runs the hero edit pipeline (section 3), so the page updates live.
6

The demo script, mapped to screens

Does every beat land on a screen above? This script is the acceptance test: the build is done when all 10 beats run on the deployed domain.

  1. Type “butter chicken”, set Ready by 7:30 PM, press Enter.
    A · Landing
  2. Cached strip appears instantly; the live agent browses; 3 cards replace it.
    B · Search
  3. Pick a card: stats strip, Start by 6:45 PM, ingredients, appliances, steps.
    C · Recipe
  4. Click “heavy cream” → coconut milk → 3 lines glow → Undo toast.
    C · Patch
  5. Try “salt → sugar”: rejected with 3 one-tap alternatives.
    C · Reject
  6. Highlight “until charred” → Explain → a tip appears under the step.
    C · Tip
  7. Click Oven → “I don't have this” → the steps are rewritten for the stovetop.
    3 · Hero loop
  8. (Optional) Chat: “make it dairy-free” → the whole recipe adapts.
    C · Chat
  9. Start cooking → “Hey Saffron, next step” → “set a timer” → “I'm out of butter”.
    D · Cook mode
  10. Save → Google sign-in → Share → open in incognito → Make it mine.
    1 · Map
